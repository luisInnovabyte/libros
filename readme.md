## 🚀 Cómo usar estos manuales

1. **Navegación**: Cada manual tiene su propia carpeta con archivos HTML/XHTML
2. **Estilos**: Todos comparten el archivo `styles.css` para mantener consistencia visual
3. **Imágenes**: Cada manual tiene su carpeta `img/` con recursos gráficos
4. **Formato**: Los manuales están en formato web para fácil navegación
