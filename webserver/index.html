2. Instalación de APACHE

🛠 2. Instala Apache

Ubuntu incluye Apache en sus repositorios predeterminados, por lo que puedes instalarlo fácilmente con el comando:

    sudo apt install apache2 -y
Este comando instala Apache y todos los paquetes relacionados.


🛠 3. Habilita y arranca el servicio

Una vez instalado, es necesario asegurarte de que Apache esté funcionando y configurado para iniciarse automáticamente al arrancar el sistema.

Habilita Apache para que inicie al encender el sistema:
  sudo systemctl enable apache2

Inicia el servicio de Apache:
     sudo systemctl start apache2

Verifica el estado del servicio:
     sudo systemctl status apache2


🛠 4. Verifica que Apache está funcionando

Abre un navegador web y accede a la dirección IP de tu servidor o localhost si estás probando localmente:


🛠 5. El acceso es:

http://**tu-ip-del-servidor**
Si Apache está funcionando, verás una página de bienvenida predeterminada de Apache que dice algo como "Apache2
        Ubuntu Default Page".

Si no conoces la IP del servidor, puedes obtenerla con:

        hostname -I ó ip a

Los ficheros se deberán colgar en: 

          /var/www/html

        
🛠 6. Versión de apache

Para asegurarte de que Apache está instalado correctamente, verifica su versión:

           apache2 -v

Esto debería mostrarte algo como:

Server version: Apache/2.4.41 (Ubuntu)
Server built: YYYY-MM-DD

3. Instalación de MYSQL

🛠 2. Instala MYSQL

Ejecuta el siguiente comando para instalar MySQL desde los repositorios oficiales de Ubuntu:
     sudo apt install mysql-server -y
Esto instalará el servidor de MySQL y los paquetes necesarios para que funcione correctamente.


🛠 3. Verifica e inicia el servicio de MySQL

Una vez instalado, asegúrate de que el servicio de MySQL esté activo y configurado para iniciarse automáticamente al arrancar el sistema.

           Inicia el servicio de MySQL:
           sudo systemctl start mysql
           
           Habilita el servicio para que arranque automáticamente:
           sudo systemctl enable mysql
           
           Verifica el estado del servicio:
           sudo systemctl status mysql


🛠 4. Configura MySQL (recomendado)

Después de instalar MySQL, es buena práctica ejecutar el script de configuración segura:

    sudo mysql_secure_installation
Este script te guiará a través de varios pasos para asegurar tu instalación de MySQL, como:

* Establecer una contraseña para el usuario root.
* Si te pregunta sobre el uso del plugin de autenticación, puedes elegir "Sí" para usar el plugin de autenticación por socket (recomendado en muchos casos) o "No" para utilizar contraseñas tradicionales.
* Eliminar usuarios anónimos.
* Deshabilitar el acceso remoto para el usuario root.
* Eliminar la base de datos de prueba.
* Recargar los privilegios para aplicar los cambios.


🛠 5. Accede a MySQL

Para verificar que MySQL está funcionando correctamente, puedes acceder a la consola de MySQL con el usuario root:

   sudo mysql

Deberías ver el prompt de MySQL:
mysql>

Desde aquí, puedes ejecutar comandos SQL.

Para salir, escribe:
exit;


🛠 6. Opcional: Instala herramientas adicionales

Si necesitas herramientas cliente para interactuar con bases de datos MySQL desde otro servidor o scripts PHP, puedes
instalar:

    sudo apt install mysql-client -y

4. Integración Apache + MySQL + PHP (LAMP stack)

Si estás configurando un servidor completo LAMP (Linux, Apache, MySQL, PHP), deberías instalar también PHP:

Instala PHP y los módulos necesarios:

     sudo apt install php libapache2-mod-php php-mysql -y


Verifica la instalación de PHP:

     php -v


Reinicia Apache para aplicar los cambios:

     sudo systemctl restart apache2

     Ahora tendrás Apache sirviendo páginas PHP y MySQL como base de datos.

El error Access denied for user 'root'@'localhost' ocurre porque el usuario root de MySQL está configurado para
autenticarse mediante el plugin de autenticación por socket y no con una contraseña. Esto es una configuración por
defecto en las versiones recientes de MySQL y MariaDB para mejorar la seguridad.

A continuación te muestro cómo solucionarlo dependiendo de tus necesidades:

🛠 Solución 1: Cambiar el método de autenticación de root a contraseña
Si prefieres que el usuario root se autentique con una contraseña (por ejemplo, para usarlo con phpMyAdmin), sigue estos
pasos:

1. Accede a MySQL usando autenticación por socket
En la mayoría de los casos, puedes acceder a MySQL como root desde el terminal sin contraseña utilizando el siguiente
comando:

sudo mysql
Esto abrirá la consola de MySQL como usuario root.

2. Cambia el plugin de autenticación
Ejecuta este comando dentro de la consola de MySQL para configurar el usuario root para que utilice la autenticación
basada en contraseña:

ALTER USER 'root'@'localhost' IDENTIFIED WITH mysql_native_password BY 'tu_contraseña_segura';
Reemplaza tu_contraseña_segura con una contraseña fuerte.

Luego, aplica los cambios:
FLUSH PRIVILEGES;

3. Prueba el acceso
Cierra la consola de MySQL:

exit;
Ahora intenta conectarte a MySQL con la nueva contraseña:

mysql -u root -p
Deberías poder acceder con la contraseña que configuraste.

6. Instalación servidor FTP

1. Instala el servidor FTP (vsftpd)

Instala vsftpd, un servidor FTP seguro y fácil de usar:

                apt install vsftpd -y


2. Configura vsftpd

Edita el archivo de configuración principal de vsftpd:
      nano /etc/vsftpd.conf


3. Busca y ajusta las siguientes configuraciones:

Permitir acceso local: Descomenta o añade esta línea para permitir a los usuarios locales iniciar sesión:
       local_enable=YES

Permitir escritura: Descomenta o añade esta línea para permitir subir archivos:
       write_enable=YES


4. Opcional: Habilitar carga de archivos grandes (recomendado):

       pasv_enable=YES
       pasv_min_port=10000
       pasv_max_port=10100


5. Crea un usuario para FTP

Crea un usuario específico para el acceso FTP:

En el ejemplo se ha creado ftpuser como usuario

      adduser ftpuser

Se te pedirá que configures una contraseña y otra información

Comando es para que el usuario creado tome posesión del directorio en el que vamos a colgar las páginas
      chown -R ftpuser:ftpuser /ruta/de/tu/carpeta


Vamos a darle permiso para poder leer escribir y ejecutar a todos los usuarios
     sudo chmod -R o+rwx /var/www

     El -R es para que sea recursivo
     El o+rwx es para que sea a todo el mundo.

     Si quiero solo permisos de ejecución a todo el mundo sería solo o+x

     Para verifcar los permisos ls -ld /ruta/al/directorio

7. Instalación servidor SAMBA



1. Instalar Samba

Ejecuta el siguiente comando para instalar Samba en tu sistema Ubuntu:
    sudo apt update
    sudo apt install samba -y

    Verifica que el servicio esté activo:
    sudo systemctl status smbd


2. Configurar Samba

El archivo de configuración principal de Samba está en 

/etc/samba/smb.conf. 

Vamos a editarlo para compartir la carpeta

/var/www/html:

Abre el archivo de configuración:

sudo nano /etc/samba/smb.conf
Añade la configuración del recurso compartido al final del archivo:


[www]
comment = directorio servidor web
path = /var/www/html
browseable = yes
writable = yes
valid users = ftpuser
create mask = 0755
directory mask = 0755

Explicación:
[www]: El nombre que aparecerá como recurso compartido en la red.
path: La ruta real de la carpeta que quieres compartir.
browseable: Permite que la carpeta sea visible en la red.
writable: Permite a los usuarios autorizados escribir en la carpeta.
valid users: Especifica qué usuarios tienen acceso (en este caso, ftpuser).
create mask y directory mask: Ajustan los permisos de los archivos y carpetas creados desde Samba.

Guarda los cambios (Ctrl + O, luego Enter y Ctrl + X).


3. Crear un usuario Samba

Samba necesita usuarios propios para autenticar conexiones. Si el usuario ftpuser ya existe en tu sistema:

Añádelo como usuario de Samba:
   sudo smbpasswd -a ftpuser
Se te pedirá que configures una contraseña para este usuario.

Habilita el usuario en Samba:
     sudo smbpasswd -e ftpuser


4. Ajustar permisos de la carpeta

Asegúrate de que ftpuser tenga acceso a la carpeta /var/www/html:

Cambia la propiedad del directorio para el usuario:
     sudo chown -R ftpuser:ftpuser /var/www/html

Asegúrate de que los permisos sean correctos:
     sudo chmod -R 755 /var/www/html


5. Reiniciar el servicio Samba

Después de realizar los cambios, reinicia el servicio Samba para aplicarlos:
     sudo systemctl restart smbd



6. Acceder al recurso compartido desde otra máquina

Desde Windows:
Abre el explorador de archivos y escribe la dirección IP del servidor en la barra de direcciones:

\\*IP_DEL_SERVIDOR*\www

   Por ejemplo:
   Copiar código
   \\192.168.1.100\www
   Introduce las credenciales del usuario ftpuser cuando se te solicite.

Desde Linux:

   Usa un gestor de archivos como Nautilus o Dolphin.
   En la barra de direcciones, escribe:
   arduino
   Copiar código
   smb://**IP_DEL_SERVIDOR**/www
     Introduce las credenciales cuando se te pidan.

8. Acceso workbench


Para solucionar el problema del acceso remoto y asegurar que se pueda conectar correctamente MySQL Workbench a la máquina virtual,
hacer los siguientes pasos y configuraciones:


Permitir conexiones remotas en MySQL

En tu máquina virtual, verifica que MySQL permita conexiones remotas. Para hacerlo:

Accede a tu máquina virtual vía SSH.
Edita el archivo de configuración de MySQL:
     sudo nano /etc/mysql/mysql.conf.d/mysqld.cnf
Busca la línea que dice:
     bind-address = 127.0.0.1
Cámbiala por:
     bind-address = 0.0.0.0
Guarda y cierra el archivo (Ctrl+O, Ctrl+X).

Si tienes acceso a phpMyAdmin, puedes realizar los mismos cambios desde su interfaz gráfica. Aquí te dejo los pasos
detallados para solucionar este problema:


Acceder a phpMyAdmin

Inicia sesión en phpMyAdmin usando el usuario root y su contraseña.
En la pestaña "Usuarios" en el menú principal:
a. Editar los Privilegios del Usuario root
   Busca el usuario root en la lista de usuarios.
   habrá una columna llamada "Host", que probablemente diga localhost.
   si necesitas acceso remoto, edita el usuario o crea uno nuevo que permita acceso desde '% (cualquier IP) o desde una IP
   específica.
   Haz clic en "Editar privilegios" al lado del usuario root.
b. Permitir Acceso Remoto
     Si el usuario root está limitado a localhost, puedes crear un nuevo usuario root que permita conexiones desde cualquier
     IP:
     Vuelve a la pestaña de "Usuarios" y haz clic en "Añadir usuario".
     Llena los campos:
     Nombre de usuario: root
     Host: % (para cualquier IP) o ingresa la IP desde la que te conectas (ejemplo: 192.168.31.130).
     Contraseña: 27979699 (o la que uses).
     Marca la opción "Conceder todos los privilegios".
     Haz clic en "Continuar".
c. Verificar los Cambios
    Después de crear o modificar el usuario, regresa a la lista de usuarios y verifica que root tenga permisos globales y
    que el host sea correcto (% o la IP específica).
d. Probar la Conexión
      Intenta nuevamente conectar desde MySQL Workbench usando las credenciales actualizadas:
      Hostname: 192.168.31.35
      Port: 3306
      Username: root
      Password: 27979699
      Si la conexión sigue fallando, verifica también que:
      
      El puerto 3306 esté abierto en el firewall de la máquina virtual.
      El archivo de configuración de MySQL (/etc/mysql/mysql.conf.d/mysqld.cnf) tenga la línea bind-address = 0.0.0.0.
