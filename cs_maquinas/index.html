Índice

  • 1. RSYNC de los Backups de PROXMOX
    • Los backups de Proxmox generalmente están en:
    
     /var/lib/vz/dump,
en el caso del HP PROLIANT DL380 G6 (proxmox) están en :
     /mnt/pve/Isos/dump

Desde la consola del NODO:
     rsync -avz -e "ssh -p 2222 -v" /mnt/pve/Isos/dump root@192.168.31.248:/Familiar_SS/LuisCarlos/CS_Apache

Esto sincronizará todos los archivos del backup de proxmox a la carpeta de Familiar_ss/LuisCarlos/CS_Apache

La parte de "ssh -p 2222 -v" hay que ponerla por que el SSH del Ra-82 se accede por el puerto 2222
La clave (siempre la va a pedir es: 27979699$C)
Hará la sincronización con el directorio mencionado.


    Pasos para crear un archivo ejecutable con rsync:
    
1️⃣ Crear el script
Crea un archivo de script con cualquier editor de texto. Por ejemplo, usa nano:

nano rsync_backup.sh
Escribe tu comando rsync dentro del archivo. Por ejemplo:

#!/bin/bash
# Script para hacer backup con rsync
rsync -avz -e "ssh -p 2222" /var/lib/vz/dump/ usuario@servidor_remoto:/ruta/destino/

Guarda el archivo (Ctrl+O y luego Ctrl+X en nano).

2️⃣ Hacerlo ejecutable
Dale permisos de ejecución al archivo para que se pueda ejecutar como un programa:
    chmod +x rsync_backup.sh

3️⃣ Ejecutar el script
Ejecuta el script usando:
    ./rsync_backup.sh

Opcional: Colocar el script en el PATH
Si quieres ejecutar el script desde cualquier lugar sin tener que escribir la ruta completa:
Mueve el archivo a un directorio que esté en tu variable $PATH. Por ejemplo, /usr/local/bin:
   sudo mv rsync_backup.sh /usr/local/bin/rsync_backup

Ahora puedes ejecutarlo desde cualquier lugar simplemente escribiendo:
rsync_backup.sh


5️⃣ Verificar con rsync en modo de solo comparación
Una opción es usar rsync en modo de solo comparación con la opción --dry-run:

rsync -avz --checksum -e "ssh -p 2222" /mnt/pve/Isos/dump root@192.168.31.248:/Familiar_SS/LuisCarlos/CS_Apache

Esto no copia ni modifica nada, pero lista los archivos que son diferentes entre el origen y el destino.
